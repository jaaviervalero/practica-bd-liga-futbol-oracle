# Base de datos de una liga de fútbol (Bases de Datos)

Práctica 1 de **Bases de Datos** (Ingeniería Informática, Universidad de Zaragoza, curso 2025-26), sobre Oracle.

- `crear_bd1.sql` y `borrar_tablas_bd1.sql`: esquema relacional (divisiones, temporadas, jornadas, equipos, partidos…).
- `poblar_bd1.sql` y `despoblar_bd1.sql`: carga y borrado de datos.
- `consulta1_bd1.sql` y `consulta2_bd1.sql`: consultas SQL.
- `trigger1.sql` y `trigger2.sql`: disparadores; por ejemplo, para archivar los nombres históricos de los equipos.

**Autores:** Javier Valero y compañeros de práctica.
